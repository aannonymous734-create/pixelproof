\subsection{One downlink, end to end}
The message is a JSON object with an \texttt{image\_png\_b64} field and a \texttt{manifest} field, posted to \cd{POST /api/v1/ingest}. The PNG is lossless, so the pixels the ground station decodes are exactly the pixels the satellite hashed unless someone changed them. The ground station decodes with a 2~MB limit and a decode guard, then calls \cd{GroundStation.process(img, manifest, live=True)}, which verifies, analyses, combines and appends to the audit log, and returns the verdict. The audit-log entry is written before the answer leaves the ground station.

The orchestration is deliberately short; this is the whole decision path (\cd{service.py}, abridged):
\begin{lstlisting}[style=py]
def process(self, img, manifest, live, source="upload"):
    with self._lock:
        if live:
            self.reload_registry()
        integrity = self.verifier.verify(img, manifest, record=live)  # proof
        content = self.detector.analyse(img)                          # evidence
        result = combine(integrity, content)                          # two-axis verdict
        result["pixel_digest"] = pixel_digest(img)
        entry = self.ledger.append({"channel": source, "verdict": result["verdict"],
                                    "integrity": integrity.status, ...})  # hash chain
        result["ledger_hash"] = entry["hash"]
        return result
\end{lstlisting}
