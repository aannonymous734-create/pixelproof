The trust layer adds nothing measurable next to the content analysis: signing and verification together take a small fraction of one millisecond, against tens of milliseconds for the forensic features and the CNN.

No GPU, cloud, hardware or paid tool is needed. Without PyTorch the system runs with the feature model alone (its own calibrated threshold), so it works on any machine with Python; the dashboard's Station page and \cd{/api/v1/health} show which mode is active. The Docker labs fit on an ordinary 8~GB laptop, and each VM of the three-VM lab fits in 1.5--2~GB of RAM. The software trust anchor and the emulated satellite are explicitly allowed by the challenge rules; the same signer interface can later sit in front of SoftHSM2 or a TPM without code changes.
