\textbf{Feature model.} Scikit-learn \cd{HistGradientBoostingClassifier} on the 48 features, four classes: authentic, resampled/spliced, copy-move, generated/inpainted.

\textbf{Pixel model (PixelNet).} A 74,116-parameter forensic CNN, in the spirit of constrained and SRM-initialised forensic networks \cite{bayar,fridrich2012}. A \emph{fixed} front end applies three SRM high-pass kernels per colour channel; residuals are truncated to $\pm3$ and concatenated with the centred RGB patch (12 channels). Then three stages of two 3$\times$3 convolutions (16/32/64 channels, batch norm, ReLU), global average and max pooling, and a linear layer. Trained with AdamW and a one-cycle schedule, using only flips and 90$^\circ$ rotations (they preserve forensic traces).

\begin{lstlisting}[style=py]
def forward(self, x):                      # x: (N, 3, 64, 64) in [0, 1]
    r = F.conv2d(x * 255.0, self.srm, padding=2, groups=3)  # 9 fixed SRM residual maps
    r = torch.clamp(r, -3, 3) / 3.0        # truncation (TLU)
    h = torch.cat([r, x - 0.5], 1)         # + centred RGB = 12 channels
    h = F.max_pool2d(self.b1(h), 2)
    h = F.max_pool2d(self.b2(h), 2)
    h = self.b3(h)
    h = torch.cat([h.mean((2, 3)), h.amax((2, 3))], 1)       # global average + max
    return self.head(self.drop(h))
\end{lstlisting}

\textbf{Fusion and decision.} $P = w\,P_{\text{features}} + (1-w)\,P_{\text{CNN}}$ with $w = {{m:/card/w_gbm|f1}}$ chosen on validation. The manipulation score is $s = 1 - P(\text{authentic})$. The alarm threshold is condition-aware: $t(x) = c + g(x)\,(p - c)$, where $g(x)$ is the probability the patch was re-encoded after capture (a second gradient-boosting model, validation accuracy {{m:/gate_val_accuracy|pct1}} \meas), $c = {{m:/card/threshold_fused|f3}}$ gives the {{m:/target_fpr|pct0}} budget on clean validation authentics and $p = {{m:/card/threshold_proc_fused|f3}}$ gives it on re-encoded ones (Section~\ref{sec:robust} explains why).
