\subsection{Limitations, with numbers}
\begin{itemize}
  \item \textbf{Smoothing of authentic patches} (blur, JPEG 2000) still raises false alarms sharply (Table in Section~\ref{sec:robust}): at JPEG 2000 rate 30 the false-alarm rate is {{r:/rows/11/false_alarm_rate|pct1}}. We do not yet distinguish benign smoothing from resampling: the patch is quarantined for review, which is a false-alarm cost.
  \item \textbf{Held-out splicing and copy-move remain the hardest families} for the shipped model: on held-out v1 splicing is detected at {{m:/models/fused (w=0.4)/test_heldout/detection_by_family/splice|pct1}} and copy-move at {{m:/models/fused (w=0.4)/test_heldout/detection_by_family/copy_move|pct1}}; on frozen v2 at {{h:/models/fused/detection_by_family/splice|pct1}} and {{h:/models/fused/detection_by_family/copy_move|pct1}}.
  \item \textbf{Localisation} is weak except copy-move (IoU {{m:/localisation_iou_mean/copy_move|f2}}; {{m:/localisation_iou_mean/splice|f2}} for splicing and {{m:/localisation_iou_mean/inpaint|f2}} for inpainting).
  \item \textbf{Integrity cannot judge content signed by a compromised source}: in scenario F1 the signature is valid for every fake and the detector flags only {{at:/scenarios/compromised_source/content_flagged|int}} of {{at:/n_per_scenario|int}}.
  \item \textbf{The audit log is tamper-evident, not tamper-proof}, and the ground-station API has no authentication or TLS (isolated lab). The optional sign-in protects the dashboard's access, not the API, and its cookies are not flagged \texttt{Secure} on plain HTTP.
  \item \textbf{In the lab, the processor key is created next to the satellite key}, and in Lab W the satellite writes the public registry that the ground station reads (emulation shortcuts). A real deployment keeps the processor key on the ground system.
  \item \textbf{Provenance-stripped edits are only as good as the detector:} of {{c:/n_products|int}} edited patches with the manifest removed, {{c:/two_axis_verdicts/strip_manifest/UNVERIFIED_NO_TRACES|int}} were released as \cd{UNVERIFIED_NO_TRACES}.
  \item \textbf{The frozen held-out v2 set has now been used to measure the effect of our changes} (Section~\ref{sec:scenario}). It is a fair before/after comparison, but it is no longer an unbiased estimate for any further change.
  \item \textbf{Lab sizes are small} (tens of messages per Docker run, {{at:/n_per_scenario|int}} trials per scenario); the {{c:/n_products|int}}-product campaign is the more meaningful trust-layer result.
  \item \textbf{The three-VM VirtualBox lab was not booted by us}; the Windows + Kali VM lab, the Docker labs and the namespace lab were run.
\end{itemize}
